# Mobilna aplikacija *Implicit Intents*
V Android Studiu sem izdelal aplikacijo Implicit Intents. Namen izdelave te aplikacije je uporaba implicitnih namenov za odpiranje spletne strani, prikaz lokacije na zemljevidu in deljenje besedila z drugimi aplikacijami. Pripravil sem uporabniški vmesnik z vnosnimi polji in gumbi, kamor lahko uporabnik vnese želeno povezavo/lokacijo/besedilo.
